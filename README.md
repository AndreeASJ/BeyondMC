# Bravo Motor Company - Landing Page

Landing page moderna y tecnológica para **Bravo Motor Company**, empresa de vehículos eléctricos.

## 🚀 Stack Tecnológico

- **Next.js 14** - App Router con SSR/SSG
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Animaciones fluidas y profesionales
- **React** - UI component library

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Build para producción
npm run build

# Iniciar servidor de producción
npm start
```

## 🎨 Características

### Hero Section
- Animaciones de entrada escalonadas
- Fondo animado con gradientes dinámicos
- Estadísticas clave del vehículo
- Botones CTA con efectos glow
- Indicador de scroll animado
- Parallax effects

### Tecnología e Innovación
- Grid de características técnicas
- Animaciones activadas por scroll (scroll-triggered)
- Cards interactivas con hover effects
- Estadísticas por característica
- Efectos de glow y gradientes
